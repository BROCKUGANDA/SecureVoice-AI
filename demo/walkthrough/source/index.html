The Dynamic Prompt Router. call_category is a closed, compile-time set of five — fact_finding, sensitive_case, b2b, routine, time_critical_fraud. It selects the agent's system prompt, its powers, and the backend preconditions enforced before a single dial. A producer that declares nothing gets the audited fraud baseline — never the weakest prompt.

03 — GUARDRAILS

The controls live in
the server, not the prompt.

The platform's Guardrails panel exposes one toggle. The real enforcement is layers deep in code that runs before, during and after every turn — so none of it can be prompted away.

TOOL BOUNDARY

Never asks for credentials

Any reply requesting a PIN, OTP or password is replaced with a safe refusal before it reaches the model.

STATE MACHINE

Never freezes alone

card_freeze only ever stages a reversible request — in every category and every environment. A human finalises it.

ENVIRONMENT GATE

Never reaches a real customer

Under APP_ENV=staging outbound telephony returns 403 and makes zero carrier calls.

AUDIT CHAIN

Every action is sealed as a row: a SHA-256 digest over the canonical serialisation, chained to the row before it. Edit any field and the link breaks from that point onward — tamper-evident by construction, exportable per case.
